# Device pictures

Exported from tracked assets in [Peripheral Desk](https://github.com/chenran0408/peripheral-desk) at commit `728f28d5c69e735590c4754fd40fbbfd57b8f865` using `git show`, without reading or replacing working-tree pictures. Device images are included for identification. Product names and artwork belong to their respective owners; this project is independent of those brands.

The G305 preview uses an original neutral mouse illustration created for this project, not a vendor product photograph.

The Basilisk V3 Pro wired preview also uses an original neutral mouse illustration created for this project. It is a placeholder for device identification, not an accurate vendor photograph or a claim about the physical appearance of the model.

The A7 V3 Ultra+ and VGN F2 Master+ previews reuse the same original neutral mouse illustration. These are identification placeholders, not vendor photographs.

The X1 Pro Max and Viper V2 Pro wired preview packages also use the original neutral mouse illustration; these are not vendor product photographs.

A9 Plus Nearlink and Viper Ultimate wired previews reuse the original neutral mouse illustration, not vendor artwork.

F2 Pro Max and F1 Pro previews reuse the original neutral mouse illustration, not vendor artwork.

DeathAdder V2 Pro wired uses the [Razer official support product image](https://assets.razerzone.com/eeimages/support/products/1714/comp_1_00000.png), downloaded on 2026-10-21 (152,930 bytes). This is vendor artwork used for product identification, not a project-created neutral illustration; the artwork and trademarks belong to Razer.

Correction for 0.4.7-preview.1: its bundled attribution incorrectly grouped this Razer image with the neutral illustrations. This paragraph and the release attribution correction supersede that statement; the package bytes remain unchanged.

AJ179 PRO and MagDock previews use the original neutral placeholder illustration, not vendor product photographs. The MagDock placeholder is not a depiction of the charging base.

The Vigil Watt migration preview images use original generic category illustrations prepared for Peripheral Desk (keyboard, mouse, headset, or accessory silhouettes with model labels). They are identification placeholders, not vendor product photos or claims about a model's exact appearance.
