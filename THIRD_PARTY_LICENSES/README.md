## Complete lockfile inventory

[MANIFEST.json](MANIFEST.json) records every registry package in the current Cargo.lock, including optional, build and target-specific crates. This is an attribution superset; not every crate is linked into every application or device DLL. Historical license files are retained.

License texts are copied unchanged from Cargo registry sources and checked against the locked registry checksum (or the cached .crate archive). Maintain them using scripts/collect-licenses.py in the main Peripheral Desk repository.
