# 迈从音频设备与原生设置

在外设盒中安装自己的型号，然后打开「设备调节」。播放与麦克风页列出这台设备已启用的 Windows 端点。每个端点的音量、静音、板载模式和均衡器都在对应页面读取当前值。多台同型号设备按 USB 物理容器区分，多个播放输出可在页内切换。

| 型号 | USB 连接 | 原生页面提供的设备功能 |
| --- | --- | --- |
| S9 Pro、G9 Pro、V9、V9 Pro | 2.4 GHz 接收器 291D:385D，按耳机自报完整名称区分 | 电量、播放和麦克风。G9 Pro 接收器固件 0006 起、V9 Pro 接收器固件 0008 起开放游戏一、游戏二及音乐模式 |
| G9 | 有线 3837:8080，名称 MCHOSE G9 WIRED HEADSET | 播放、麦克风 |
| X9 | 2.4 GHz 接收器 3837:6045 | 电量、播放、麦克风、两组游戏及音乐模式 |
| V9 Pro 2、R9 | 2.4 GHz 接收器 3837:6011、3837:6013 | 电量、充电、播放、麦克风、三套十段板载 EQ、提示音量、自动关机。板载模板保存和恢复三套 EQ 的名字、增益与当前槽 |
| V9 Turbo、V9 Turbo+ | 2.4 GHz 接收器 3837:600D、3837:600A | 电量、充电、播放、麦克风、三种音效模式、提示音量、15/30/45 分钟关机 |
| G20、G20 Pro | 有线 0E6A:0111，按 USB 产品名识别；通用产品名走字符串描述符 5 | 播放、语音提示。USB 固件 0160 起支持音乐、游戏及电影模式 |
| K20、K20 Pro | 有线 3837:60C4、3837:6003 | 播放、语音提示、三种音效模式、灯效模式、亮度、周期、灯组和颜色 |
| K20 GT | 有线 3837:60C6 | 播放、语音提示、三种音效模式、智能灯光、灯效亮度/周期/颜色、屏幕开关、主题与颜色 |

本版依照固定 M HUB 前端的型号表、协议和功能条件改写为 Rust。参考代码为 M HUB `main-DIt5vAcV.js`。官方文件 SHA-256 为 `cb10c9d3d29505bef2e2d3207dbe223601ff84c46d772b4a0f1e93ef02391c1b`，外设盒 0.4.12-preview.3 附带的本地修订文件 SHA-256 为 `35f12a6ad01649d7d51bc51ad899ace1cedd6d7f8ccfa9563e886e6565eab522`。驱动请参考 `createAudioHidProduct`、`protocolsByProfile`、`createOnboardEqOperations` 与各型号的功能范围判断。[M HUB 固定前端](https://www.mchose.com.cn/assets/main-DIt5vAcV.js)

本项目用软件样本校验 MC 命令、读回、十段增益和模板范围。Windows 端点按容器筛选还在本机 USB 音频设备上进行了只读核对。以上型号的新板载写入与听感仍待实物验证。V9 Pro、X9 的既有电量来源继续单独记录。蓝牙、V9 Turbo+ 底座、只在官方桌面客户端登记的旧型号及其他同名接收器均需各自的适配依据。

原版音频运行时区分 THX 和 C-Media。桌面虚拟环绕、THX 效果、麦克风降噪和由 C-Media SDK 处理的软件 EQ 尚未原生接入。G20 缺少板载灯效读回，BLK 的软件灯效档案、K20 GT 动画图片上传、滚动歌词与桌面音乐联动仍在本版原生页面范围之外。
