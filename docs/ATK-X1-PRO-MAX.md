# ATK X1 Pro Max

`atk-x1-pro-max` is a read-only preview for the wired mouse (`373B:1017`) and its 8K receiver (`373B:101B`). Both verified upstream paths use interface 1, HID usage `FF02:0002`, report ID `08`, and 16-byte input/output payloads. The Windows HID buffer includes the report ID, so the driver requires 17-byte input and output reports and the `MI_01` interface path. It excludes the 1K receiver (`373B:101A`).

Before reading battery state, the driver sends identity command `10`. The reply must have command `10`, success status `00`, a valid report checksum, a declared three-byte payload, and CID/MID `02:27` (decimal `2,39`). Only then does it send battery command `04`. Its reply must have command `04`, status `00`, a valid report checksum, and exactly two declared data bytes: percentage (0–100) and charging (`00` or `01`). The other bytes in the captured report are padding and are ignored. No EEPROM, settings, pairing, lighting, or other commands are sent.

The protocol implementation is newly written from public protocol facts; it does not copy or link OpenMouse code. Source evidence is pinned to OpenMouse `mouse-protocol` commit [`bac031567b28f2a55c616fc525b03f2d5fa452cc`](https://github.com/OpenMouse-Project/mouse-protocol/tree/bac031567b28f2a55c616fc525b03f2d5fa452cc): [`docs/atk-testing.md`](https://github.com/OpenMouse-Project/mouse-protocol/blob/bac031567b28f2a55c616fc525b03f2d5fa452cc/docs/atk-testing.md) identifies the verified X1 Pro Max connections and records raw identity and battery frames in [`captures/atk-x1-pro-max/wired.json`](https://github.com/OpenMouse-Project/mouse-protocol/blob/bac031567b28f2a55c616fc525b03f2d5fa452cc/captures/atk-x1-pro-max/wired.json) and [`captures/atk-x1-pro-max/receiver.json`](https://github.com/OpenMouse-Project/mouse-protocol/blob/bac031567b28f2a55c616fc525b03f2d5fa452cc/captures/atk-x1-pro-max/receiver.json). [`src/drivers/atk/hid.ts`](https://github.com/OpenMouse-Project/mouse-protocol/blob/bac031567b28f2a55c616fc525b03f2d5fa452cc/src/drivers/atk/hid.ts) documents commands `10` and `04` and the reply offsets; [`src/endgame-gear/wireless.ts`](https://github.com/OpenMouse-Project/mouse-protocol/blob/bac031567b28f2a55c616fc525b03f2d5fa452cc/src/endgame-gear/wireless.ts) documents the report-08 checksum framing used by the ATK transport. ATK HUB 3.2.27 maps CID/MID `2,39` to X1 Pro Max; the upstream hardware-testing page cites the vendor application bundle.

The upstream repository is licensed under GNU AGPL v3. This crate contains no copied upstream source code; its implementation is independently written. This package has not been tested with local hardware. The fixed upstream records document real hardware reads, but the preview does not claim local validation.
