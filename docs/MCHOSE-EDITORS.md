# 迈从设备在外设盒中能调什么

预览版 .51 增加 26 款磁轴键盘、15 款音频设备的原生控制，并将 17 款鼠标的本地模板接入外设盒。[查看型号、支持范围与安装方法](MCHOSE-NATIVE-FAMILIES.md)


在「设备调节」选择具体设备。电量在设备详情及托盘查看。表中型号均有独立插件，可在「插件管理」搜索和安装。表中列出当前预览通道的功能，旧版插件可能只提供其中一部分。

**原生**栏列出由外设盒与插件直接提供的能力。「上游实机」等验证标记只覆盖型号档案列出的操作、接口与固件，不能外推到同一行所有写入。「网页」指随安装包离线提供的 M HUB。有可选页面时仍须接入对应设备并完成身份识别。原版网页允许浏览型号、图片或布局，实际操作由设备回复决定。[查证据与原始来源](../catalog/README.md) · [软件与插件下载](https://github.com/chenran0408/peripheral-desk/releases)

## 哪些设置继续使用本地 M HUB

| 范围 | 入口、条件与缺项 |
| --- | --- |
| 新鼠标的板载槽与宏 | 原生页根据插件实际回复开放设置、宏槽与动作。原版鼠标页仍可使用其余已适配的操作。现有网页模板在原工作区继续编辑。原生配置导入只处理对应设备支持的格式。 |
| 机械键盘 | G75 Pro 原生普通、Fn、Fn2 三层及逐键灯均读实际板载块。板载宏可选单次、按住重复、按其他键停止，原生宏页按需读取。旧版改键与逐键灯网页保留在个人工作区。其他已列键盘的原生插件目前提供电量，原厂布局由其网页型号识别选定。 |
| 磁轴键盘 | 本地磁轴网页包含 83 份型号/修订布局。设备提供时可显示键程、RT、DKS、SOCD 等。原生触发、校准编辑器尚未接入，网页的各型号实机写入覆盖见主程序兼容表。A7 Magnetic 是鼠标。 |
| 迈从音频 | 原版网页随设备声明显示声音、麦克风、均衡器、灯与屏幕等项目。桌面音频运行时及实际写入按型号检查。V9 Pro、X9 的原生电量插件均未实现原生调音。 |
| 联动 | LightSync 仍在本地网页，需要参与设备及采集环境配合。实体多设备同步尚未验收。厂商桌面进程提供的屏幕同步、游戏交互、跟随前台应用切换板载档，以及后台热力图，均未接入。 |
| 本地工作区 | 原有模板、可编辑的旧网页、CSS、脚本仍可从对应工作区打开。厂商账号、云同步及社区发布均不在本地功能范围内。 |

**同名 A7 V3 Ultra+ 的接收器差异。** 指定插件同时要求 `3837:1018`、主机名称 `MCHOSE A7 V3 Ultra+` 及抓包中 `0x0900` 的 `4026`。原厂鼠标参数表中 A7 V3 Ultra+ 机身 PID 为 `4033`，另有 A5 V3 Ultra+ 使用 `4026`。厂家名称和接口必须一并核对。没有在此插件中加入该鼠标线缆模式。[上游抓包与范围](MCHOSE-A7-V3.md)
