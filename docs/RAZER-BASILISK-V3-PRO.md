# Razer Basilisk V3 Pro Wired Preview

Package: `razer-basilisk-v3-pro-wired-driver` (`0.4.9-preview.1`). This plugin adapts public OpenRazer protocol facts and has not been tested with a physical mouse.

## Supported model and settings

- Wired USB Basilisk V3 Pro only: VID/PID `1532:00AA`. The receiver (`00AB`) and 35K variants are excluded.
- The driver opens only one HID interface matching `MI_00`, a 91-byte Feature report, and the exact wired PID. The 91-byte Windows buffer includes the Report ID; no physical descriptor capture was available. It sends no command if zero or multiple interfaces match.
- Reads battery, charging, DPI, polling rate, and overall lighting brightness. It can set DPI from 100 to 30,000 in 50-DPI increments, polling rate at 125/500/1,000 Hz, and brightness from 0 to 255. Each setting is read before writing, verified afterward, and restored with readback verification if the write or check fails. DPI changes preserve other stages and unknown table bytes.
- The lighting editor writes upstream-supported static color, spectrum, and wave effects. Brightness can be read from the mouse; current effect and color cannot. The app keeps the last configuration it successfully sent, and clearly labels it as saved app state rather than hardware readback. Button remapping and macros are not listed by upstream for this model and remain unavailable.
- Battery level is converted from the device's 0–255 reading to percent. Charging is accepted only as 0 or 1. Hardware and firmware remain unknown.

## Protocol evidence

The implementation follows OpenRazer commit [`477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d`](https://github.com/openrazer/openrazer/tree/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d). Its [Basilisk V3 Pro wired model declaration](https://github.com/openrazer/openrazer/blob/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d/daemon/openrazer_daemon/hardware/mouse.py#L1694-L1728) lists DPI and stages (maximum 30,000), polling rate, battery, charging, brightness, and supported effects. The [mouse driver](https://github.com/openrazer/openrazer/blob/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d/driver/razermouse_driver.c#L32-L101) uses report index 0 and the standard 31 ms wait. Its battery and charging requests use transaction ID `0x1F` ([battery](https://github.com/openrazer/openrazer/blob/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d/driver/razermouse_driver.c#L1592-L1668), [charging](https://github.com/openrazer/openrazer/blob/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d/driver/razermouse_driver.c#L1706-L1775)); the DPI, stage, and polling paths use the same model selector and transaction ID in the [DPI](https://github.com/openrazer/openrazer/blob/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d/driver/razermouse_driver.c#L2548-L2660), [stage](https://github.com/openrazer/openrazer/blob/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d/driver/razermouse_driver.c#L3162-L3227), and [polling](https://github.com/openrazer/openrazer/blob/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d/driver/razermouse_driver.c#L1949-L2005) handlers. OpenRazer's shared constructors define the DPI/stage and polling command fields ([DPI](https://github.com/openrazer/openrazer/blob/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d/driver/razerchromacommon.c#L1211-L1241), [stages](https://github.com/openrazer/openrazer/blob/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d/driver/razerchromacommon.c#L1281-L1325), [polling](https://github.com/openrazer/openrazer/blob/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d/driver/razerchromacommon.c#L1092-L1127)). Brightness is handled through the extended matrix brightness commands and wired-model ID (`0x1F`) ([brightness handler](https://github.com/openrazer/openrazer/blob/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d/driver/razermouse_driver.c#L4280-L4385), [constructors](https://github.com/openrazer/openrazer/blob/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d/driver/razerchromacommon.c#L709-L741)). The shared report is 90 bytes and uses the documented XOR checksum ([layout](https://github.com/openrazer/openrazer/blob/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d/driver/razercommon.h#L124-L136), [checksum](https://github.com/openrazer/openrazer/blob/477f4d6d3ab7e9deb6310d5bd3742560c5cbe80d/driver/razercommon.c#L108-L124)).
