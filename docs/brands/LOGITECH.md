# Logitech / 罗技

新驱动：`logitech-g304` 与 `logitech-g305`，均为**公开实现适配未实测**的预览插件。两者共享 `046D:C53F` / WPID `4074`，运行时通过完整设备名分开识别。

仅 `046D:C53F` 接收器的 slot 1、`FF00:2` 长报文，并要求 HID++ 4.2、公开 WPID `4074` 和对应完整名称全部匹配。G304 与 G305 共享接收器和 WPID，但不会互相冒认；没有对其他 Logitech 设备自动泛化。两者均只读电量，设置/宏/灯光均未开放。
