# 迈从 MCHOSE

预览版 .51 增加 26 款磁轴键盘、15 款音频设备的原生控制，并将 17 款鼠标的本地模板接入外设盒。[查看型号、支持范围与安装方法](../MCHOSE-NATIVE-FAMILIES.md)


在[厂商目录的迈从分区](../../catalog/README.md#vendor-mchose)按键盘、鼠标、耳机与底座查找具体插件、功能和验证范围。每个条目独立安装。接收器底部或包装标识不清楚时，在驱动商店查看实际检测到的 USB 接口，再选择对应的型号和接收器。

| 设备与连接 | 对应功能与识别边界 |
| --- | --- |
| A5 Ultra 初代普通接收器 | `3837:100C`，FF01、取反 Feature、精确产品名。已有电量、设置和六键改键；宏仅在能保留原宏页时可写。新版 A5 V2 Ultra 在上游也登记这个接收器 VID/PID。 |
| A7 V3 Ultra+ 8K 接收器 | `3837:1018`，0x4D 通道。外设盒现有包核对主机产品名与 0x0900 实物样本中的内部身份后，提供电量、DPI、无线回报率、六键映射。上游通用目录中的型号编号与此实物样本有差异。 |
| G75 Pro、K99 V2 | 共用 `3554:FA09`。G75 Pro 的设置、改键、灯效和板载宏上传与绑定已有本项目实机记录。K99 V2 是用户认领的独立电量插件。 |
| G87 V1、G87 V2 的 V1 会话接收器 | 分别为 `41E4:2001` 和 `3837:201B`，使用 FF02 的 20 字节接口。两个版本按自己的握手应答读取。 |
| G87 V2 的 CZ 接收器 | `3837:3033`，MI_02 / FF31:0074。上游贡献者实测读取电量与充电。确认型号后在预览通道选“CZ 接收器”。同接收器的 G75 V2、K87S、K99 V3 尚无该路径的同等验证。 |
| A7 V2 Pro、A5 Pro Max、A7 V2 Ultra、M7 Ultra、G7 | 各包声明可用路径。A7 V2 Pro 优先接收 E2 上报，A5 Pro Max 使用 0x83，A7 V2 Ultra 与 M7 Ultra 共享取反 0x06 协议，G7 使用 AA 30 应答。 |
| V9 Pro 与 X9 耳机 | 两款耳机使用 55 65 查询，各有独立接收器、应答判据和验证记录。V9 Pro 的早期上游设备记录只确认了满电样本。 |
| MagDock 底座 | `3837:1012`，通过底座专用的 FF00 接口设置灯效。 |

固定研究资料包含 Vigil Watt 的[厂商设备表](../../catalog/upstream/vigil-watt/mchose-catalog.json)和[协议规格](../../catalog/upstream/vigil-watt/mchose.protocols.json)。设备表里的 `transports` 描述接收器，`devices` 描述产品型号。某条通道已支持读电量，只说明该资料里列出的接口和观察范围。

预览商店提供 [16 款通用 8K 接收器鼠标的分型号插件](../../crates/protocol-mchose-0x4d/UPSTREAM.md)。详情读取当前板载配置的 DPI 档位（性能查询缺失时读取配置 0）、设备报告的活动档位以及配置回报率；X/Y 轴独立时分开显示。

这 16 款鼠标可在原生键位图上选择按键、录入板载宏，或将按键设成 DPI 加一档、减一档。A7 Magnetic 和 R7 Ultra 各有五个可编辑键；其余型号的第六键以设备回复为准。配置与宏均按当前选定的鼠标读取。[各型号图形与协议范围](../MCHOSE-EDITORS.md)

[K5 V2](../../drivers/mchose-k5-v2) 使用独立的 3837:101C 接收器和 4040 配对身份，也支持五键图形编辑、42,000 DPI 和三档抬升距离。
