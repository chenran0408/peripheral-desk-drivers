# VGN

当前为调查候选，**本轮没有新 VGN 可安装支持声明**。

优先候选 F1 Pro：公开表列3554:F503接收器 / F502有线。另有 F2 Pro Max 的FB3E/FB3D；OpenMouse 的 VGN F2 adapter 则明确只匹配FB56/FB57。这些后缀、代际和PID不应互相推广。

先验证精确PID、FF02集合与17字节报告、运行时型号和电量只读应答；先不迁移profile、DPI或按键写入。VGN/VXE/ATK的商业命名可能交叉，3554也出现在MCHOSE键盘；不能按VID或“同为Compx方案”全接入。

完整来源与许可证见 [调查矩阵](../PROTOCOL-RESEARCH.md)。
