# ROG Gladius III Wireless AimPoint 36K

- [AriseFX/rogdrv-web](https://github.com/AriseFX/rogdrv-web), GPL-3.0: **协议事实参考，未复制代码**. Its reported scope is receiver `0B05:1A72`, cable `0B05:1A70`, FF01:0001 collection and GET_BATTERY `0x0712` (wire bytes `12 07`), with percent in reply byte 4 and charge in byte 9.
- Bluetooth `0B05:1A74` is expressly excluded. Peripheral Desk implementation is independent, read-only, and has not been tested on hardware. No GPL source code or assets are copied into this package.
