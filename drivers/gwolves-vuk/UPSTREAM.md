# G-Wolves VUK

- Protocol and IDs: [HaloBattery gwolves.py](https://github.com/HeyOkay/HaloBattery/blob/2251f0534a8e886c9692ead42056059b4f69d8c0/providers/gwolves.py) and [protocol notes](https://github.com/HeyOkay/HaloBattery/blob/2251f0534a8e886c9692ead42056059b4f69d8c0/docs/protocols.md) (MIT); originally mapped from the [G-Wolves web driver](https://mouse.xyz) device table (license not asserted).
- `33E4:3917` receiver, `33E4:3908` cable. Old `0x8F` feature exchange, 65-byte feature collection. These IDs do not share a receiver with another listed model.
- Code adapter only. HaloBattery's list does not claim hardware validation for this model; Peripheral Desk has not tested it on hardware. Independently implemented from protocol facts.
