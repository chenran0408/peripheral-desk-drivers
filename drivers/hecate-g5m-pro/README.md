# HECATE G5M Pro

Read-only 2.4 GHz receiver status for exactly 35BB:D00B, usage FF1C:0092, 64-byte reports. Sends the documented report-04/marker-1A battery query and accepts only matching status frames with a 1–100 raw percent. Charge flags 00/01/02 map to discharge/charging/full; other flags remain unknown. Vigil Watt v1.3.0 reports contributor hardware verification; the Vigil Watt maintainer did not retest this unit. This plugin actively sends one read-only query per state request. DPI, remapping, macros, lighting, and audio are not included.
