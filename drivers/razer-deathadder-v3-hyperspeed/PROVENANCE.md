# Razer DeathAdder V3 HyperSpeed

This package matches only the Razer receiver PID 1532:00C5 and a 91-byte Feature interface. It reads the battery value through the command channel documented by Voltide's Razer provider. The independent DPI-stage and report-rate operations in preview.46 are based on the model definitions and mouse protocol in OpenSynapse v1.7.2. See [settings support and sources](../../docs/RAZER-OPENSYNAPSE.md).

The adapter is an untested preview. The receiver PID is kept exact so this package cannot claim support for other Razer models or shared receiver identities.
