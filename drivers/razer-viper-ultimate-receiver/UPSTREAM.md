# Razer Viper Ultimate receiver

This independent Rust adapter follows the battery query in Voltide v2.1.2 (`73f16fd2be44570c0a861cef6b4804d743656893`), whose `RazerProvider` lists receiver PID `1532:007B`. It is distinct from the existing wired Viper Ultimate plugin (`1532:007A`). Only battery/charging readback is implemented; Peripheral Desk has not independently tested the hardware. Upstream MIT license text is included in the shared plugin package notices.
