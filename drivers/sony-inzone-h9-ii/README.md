# Sony INZONE H9 II (WH-G900N2)

Read-only battery and charging for the 054C:0FA8 receiver interface MI_05/COL03, FF04, 64-byte report 0x02. The query uses Windows HID control `SET_REPORT`; interrupt output is known to echo the request and is deliberately not used. Vigil Watt v1.3.0 documents maintainer hardware validation, including 78% battery and charge-state checks. USB receiver mode only; EQ, volume, lighting, and settings are not implemented. Source and MIT attribution are in the protocol crate.
